# AGENT.md — Coding-assistant instructions for Lumeo Campaign Studio

> **Audience.** AI coding assistants (Copilot, Cursor, Codex, Aider, Continue,
> etc.) and human contributors. This file tells you how to work in this
> repository safely and consistently.
>
> **Read order:** `README.md` → `WORKFLOW.md` → this file.

---

## 1. Project overview

Lumeo Campaign Studio is a multi-agent platform that turns a free-form
marketing brief into a reviewable, multi-channel execution plan. Three
workflows on one backend:

1. **Plan from Brief (W1)** — paste brief → clarify → plan → review → approve.
2. **Brief QA (W2)** — paste any brief or plan → audit it.
3. **Asset Consistency (W3)** — drop in 3+ marketing assets → cluster
   terminology, recommend canonical CTAs.

The backend is FastAPI; the orchestrator is LangGraph (in-process); the UI is
Streamlit; the LLM is Azure OpenAI; storage is Postgres + Qdrant + Redis.

See `WORKFLOW.md` for ADRs, phase history, and the stack table. See `README.md`
for setup, run, and demo instructions.

## 4. Build, run, and test commands

```bash

pip install -e ".[dev]"

# infra
docker compose -f docker-compose.infra.yml up -d
```

## 5. Code conventions

### Style
- **Black** + **ruff** are the formatters; pyproject.toml has the config. Don't
  introduce a new formatter.
- Type hints required on every public function. Pydantic v2 schemas wherever
  data crosses a boundary.
- Async/await throughout the API and agent layer. No blocking I/O on the
  request thread — wrap with `asyncio.to_thread` if you must.
- Naming: snake_case for variables/functions, PascalCase for classes, UPPER for
  module-level constants. File names match the primary class.

### Module boundaries
- `agents/` — one file per agent. Stateless. One input, one prompt, one
  Pydantic schema, one output. No agent-to-agent calls; the orchestrator
  wires them.
- `orchestrator/` — LangGraph graph + nodes + interrupt handling. This is the
  only place that knows about agent execution order.
- `core/llm/gateway.py` — the **only** path to Azure OpenAI. Bypassing it
  skips cost tracking, trace logging, retry, and budget cap. See § 7.
- `core/schemas/` — Pydantic v2 schemas. Persistence schemas have UUID/datetime
  fields; their LLM-bound `XxxExtraction` siblings drop those fields. See § 7.
- `api/routes/` — thin HTTP layer. No business logic. Calls into orchestrator
  nodes, returns Pydantic responses.
- `ui/` — Streamlit. Calls the API via `httpx`; never imports from
  `agents/` or `orchestrator/` directly.
- `tools/` — pure Python primitives (completeness scoring, brand voice
  scoring). No LLM calls. Easy to unit-test.

### Comments
- Default to no comments. Use them only when WHY is non-obvious — a hidden
  invariant, a workaround for a specific bug, a constraint that's not
  visible from the code.
- Don't paraphrase what the code does in a comment. Names should do that.
- Don't add "added for issue #123" or "called by X" comments — those rot.

## 7. Architectural invariants — do not break

These are recurring failure modes. Honor every one. Each entry below has cost
us at least one bug — that's why it's an invariant.

1. **Extraction-schema pattern (ADR-009).** Every LLM-bound schema with
   auto-generated fields (UUID, datetime) has a sibling `XxxExtraction`
   schema that DROPS those fields. Agents call
   `call_structured(output_schema=XxxExtraction)` and promote via
   `to_brief()` / `to_gaps()` / etc. Reason: `core/llm/structured.py:_strictify`
   force-overwrites `required` to include every property (Azure strict-mode
   demands it), so the LLM is forced to emit every field. It can only emit
   `null` for server-generated UUIDs/timestamps, which then 400s on Pydantic
   validation. Examples: `BriefExtraction`, `GapListExtraction`,
   `QuestionListExtraction`, `PlanSkeletonExtraction`, `ChannelPlanExtraction`,
   `CopyDraftExtraction`, `ResolvedObjectiveExtraction`,
   `TimelineWeekExtraction`, `ValidationReportExtraction`,
   `CTAFindingExtraction`, `CanonicalSuggestionExtraction`.
   **Do NOT bind LLM calls to schemas with auto-generated fields.**

2. **`Brief.raw_source` is immutable.** Overrides go through
   `orchestrator/interrupts.py:apply_overrides_to_brief` + `BriefOverride`
   rows. `briefs.parsed_json` IS rewritten via `flag_modified` after
   `apply_overrides_to_brief` — that's the enriched view downstream agents read.

3. **ADR-008 override-routing safety net.** Free-text answers targeting
   list-typed top-level Brief paths (`quantified_targets`,
   `success_metrics`, etc.) are auto-routed to
   `constraints.mandatory_inclusions` as `[override:{path}] {value}` audit
   lines. The Clarifier WILL emit these paths; do NOT "fix" the prompt to
   avoid them. The `/api/v1/briefs/{id}/overrides` endpoint returns 422
   (with `field_paths`) on residual ValidationError — never 500. The audit
   prefix is scrubbed from the rendered surface only via
   `ui.styles.scrub_override_prefix(text)` — NEVER write the scrubbed form
   back to storage.

4. **`CampaignState` is `extra='forbid'`.** Side-channel data lives in
   Redis: `copy_drafts:{sid}:{pid}`, `dialog:{sid}`, `demo:c:payload`,
   `demo:d:payload`. Don't add transient runtime fields to `CampaignState`.

5. **Brand voice fingerprint.** Loaded via
   `knowledge/brand_voice.py:get_or_build_fingerprint(db, brand_name)`.
   Auto-builds from `seeds/brand_voice_samples/{brand_lc}_on_voice.txt`
   and `_off_voice.txt` on first call. File naming MUST be lowercase brand
   name. When unavailable, `agents/copy_drafter.py` sets
   `voice_score_breakdown={"fingerprint_available": 0.0}` so the UI shows
   `🟠 fingerprint missing` instead of pretending 0/100 is real. **Never
   restore the silent `voice_score=0.0` fallback.**

6. **`CopyDraft.angle` always renders.** Required-with-default field
   (`"outcome-led"`). UI must never render `?` — schema default +
   `_resolve_angle` keyword fallback (urgency / proof / enterprise /
   ROI / speed / pain / benefit) guarantee a non-empty value. NEVER remove
   this field or its default.

7. **Copy preview rendering.** All copy bodies pass through
   `agents/copy_drafter.py:_sanitize_body` server-side. UI page 1 renders
   bodies via an HTML `<pre class='lumeo-copy-pre'>` inside
   `lumeo-copy-frame` — NOT a disabled `st.text_area` (the textarea
   introduced inner-scroll overlap artifacts).

8. **Cost meter.** `observability/cost_meter.py:get_cost_snapshot` SUMs
   `trace_events.cost_usd` (the authoritative ledger). Falls back to
   `sessions.cost_usd` only when events sum to zero. Cache hits land at $0
   in trace (correct). **Do NOT revert to reading `row.cost_usd` directly.**

9. **Qdrant client.** Use `client.query_points(...).points`
   (qdrant-client ≥ 1.10 removed `client.search`). The wrapper at
   `core/embeddings/qdrant_store.py` already handles this.

10. **No fabricated numbers in prompts.** Every prompt enforces "do not
    invent budget / dates / metrics" — preserve this language.

11. **Bounded revision in code, not prompt.**
    `orchestrator/nodes.py:MAX_REVISIONS = 2`. NEVER raise above 2 or
    remove the cap.

12. **Governance scanners are deterministic.** `agents/governance.py` must
    NEVER make LLM calls. The merge-with-alignment-penalty math depends on
    that determinism.

13. **`extra='forbid'` on every schema** via `core/schemas/base.py:StrictModel`.

14. **Channel cap is 3 (ADR-003).** Hallucinated channels (not in seed
    catalog) are dropped by the planner.

15. **W3 cosine threshold τ = 0.70 (ADR-006).** Replacing with HDBSCAN
    requires reverting that ADR.

16. **Cache key formula:**
    `sha256(prompt_name + version + variables + schema_name)`. **Never
    change** — invalidates production caches.

17. **No direct Azure OpenAI SDK calls.** Only `core/llm/gateway.py` and
    `core/embeddings/client.py` may call the Azure SDK directly.
    Bypassing skips cost tracking, trace logging, retry, and budget cap.

18. **Observability never crashes a real call.**
    `observability/trace.py:log_event` swallows exceptions — preserve
    that contract.

## 8. Testing approach

- **Unit tests** use in-memory fakes (`monkeypatch.setattr` to swap in
  fake DB / fake Redis). They do not require infrastructure to run.
  Patterns to copy: `tests/unit/test_observability.py` and
  `tests/unit/test_briefs_recent_endpoint.py`.
- **Integration tests** (`-m integration`) need the storage stack
  running and a valid `.env` with Azure credentials.
- **Eval golden set** lives at `seeds/golden_set/`. Each brief has
  `_expected_gaps.yaml` (and optionally `_expected_plan_shape.yaml`).
  `scripts/run_eval.py` exits non-zero on any errored item.
- When you change a prompt, **bump its version** (`v1.jinja` → `v2.jinja`)
  — the cache key includes prompt version, so old cache entries are
  invalidated automatically.
- Add a unit test for any new agent. Add an integration test if the
  change touches the orchestrator graph or a new external dep.

## 9. Common tasks for an AI assistant

### "Add a new agent"
1. Add the schema (and an `XxxExtraction` sibling if it uses LLM
   structured output) in `core/schemas/`.
2. Add the prompt at `prompts/{agent_name}/v1.jinja`.
3. Add the agent at `agents/{agent_name}.py` following the `Agent`
   protocol in `agents/base.py`.
4. Wire it into `orchestrator/nodes.py` and `orchestrator/graph.py`
   if it should be on the main path.
5. Add a unit test at `tests/unit/test_{agent_name}.py` using
   monkeypatched LLM gateway.
6. Update `WORKFLOW.md` and `AGENT.md` agent counts if material.

### "Add a new HTTP endpoint"
1. Pick the right router under `api/routes/`.
2. Define request/response Pydantic models *next to the route* if not
   reused, or in `core/schemas/` if reused.
3. Call into orchestrator nodes (don't put business logic in the
   route).
4. Register the router in `api/main.py` if it's a new file.
5. Add a unit test at `tests/unit/test_{route}.py`.

### "Change a prompt"
1. Bump the version: `prompts/{agent}/v1.jinja` → `v2.jinja`.
2. Update the agent that loads it (or rely on the loader's
   `version='latest'` default).
3. The cache key changes automatically — no manual flush.
4. Run the affected unit tests + the relevant integration test.

### "Add a new export format"
1. Add the renderer at `export/{fmt}_exporter.py` returning bytes from
   a `BytesIO`. Pure Python preferred (no system deps).
2. Add the format to the `Literal` in `api/routes/export.py` and pick a
   sensible content-type.
3. Surface it as a download button in `ui/pages/1_Plan_from_Brief.py`
   if it should be user-facing.
4. Add a unit test at `tests/unit/test_exporters.py`.

## 10. Security and safety constraints

- **Never commit `.env`** — it has Azure keys. `.env` is in `.gitignore`.
- **No fabricated numbers in prompts** — every prompt has the rule
  "do not invent budget / dates / metrics." Preserve it.
- **All copy bodies are sanitized server-side** before storage and
  before render — see `agents/copy_drafter.py:_sanitize_body`.
- **Per-session budget cap** is enforced by the gateway via
  `BudgetExceeded`. Default `SESSION_BUDGET_USD=1.00`. Don't disable.
- **Trace events redact nothing** — they store the full prompt + response
  for debugging. If you process briefs with PII, scrub before persisting.
  Multi-tenancy and per-tenant audit are out of scope for this build.
- **No network calls outside the LLM Gateway and Embeddings Client.**
  No telemetry, no analytics, no third-party SDK calls — keep the
  deploy surface auditable.

## 11. Out-of-scope (do not silently add)

- Live ad-platform integration (Meta / Google / LinkedIn ads APIs).
- Autonomous publishing — every workflow ends with human approval.
- A/B test infrastructure (statistical rigor not in scope).
- CRM / MAP OAuth integrations.
- Real-time budget optimization against live spend data.
- Multi-tenancy and authentication.
- Replacing the in-process orchestrator with a worker queue (Tier 2
  refactor, deferred).

If you think the project needs any of the above, propose it in a
`WORKFLOW.md` ADR first. Don't add it inline.

## 12. Where to look first when something breaks

| Symptom | Look at |
|---|---|
| 422 on `POST /briefs/{id}/overrides` with `field_paths` | Working as designed (ADR-008). UI scrubs the audit prefix at render time. |
| Voice score = 0/100 in UI | `seeds/brand_voice_samples/{brand_lc}_*` files missing. Check `knowledge/brand_voice.py:get_or_build_fingerprint`. |
| Cost meter shows $0 after real LLM calls | `observability/cost_meter.py:get_cost_snapshot` — must SUM `trace_events.cost_usd`, not read `sessions.cost_usd`. |
| Critic loop never terminates | Check `MAX_REVISIONS` constant in `orchestrator/nodes.py`. Hard cap = 2. |
| Streamlit page reload doesn't reflect a CSS change | Module-level state survives page reload; restart Streamlit and clear caches. |
| Strict-mode JSON-schema 400s with "null on required field" | The bound schema has an auto-generated field. Move to an `Extraction` sibling (ADR-009). |
| Qdrant call fails with "no attribute search" | Use `client.query_points(...).points` — the wrapper handles both call shapes. |
